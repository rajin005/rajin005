# Data-Driven Pressure State Classification for Hydrogen Refueling Stations

Reproducible code and data for the paper *"Data-Driven Pressure State Classification for Safe and Reliable Operation of Hydrogen Refueling Stations."*

This repository classifies the buffer-tank pressure state (**HIGH / MEDIUM / LOW**) of a hydrogen refueling station (HRS) using six temperature and flow signals, with buffer pressure explicitly excluded from the input features to prevent target leakage. A Multi-Layer Perceptron (MLP) is benchmarked against Logistic Regression, a Decision Tree, and a Random Forest.

## Results Summary

| Model | Accuracy | Precision | Recall | F1-Score |
|---|---|---|---|---|
| **MLP (proposed)** | **0.9798** | 0.9799 | 0.9798 | 0.9798 |
| Random Forest | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| Decision Tree | 0.9976 | 0.9976 | 0.9976 | 0.9976 |
| Logistic Regression | 0.6268 | 0.6340 | 0.6268 | 0.6289 |

Random Forest and Decision Tree reach ceiling accuracy because the underlying simulation data is noise-free; this is discussed in the paper as a limitation, not a deployment claim. The MLP is the proposed model on the basis of its calibrated confidence behavior (Section 3.7 of the paper).

## Reproducing the Results

```bash
git clone <this-repository-url>
cd <repository-name>
pip install -r requirements.txt

python src/01_combine_scenarios.py     # → data/processed/synthetic_data_labeled.csv
python src/02_train_test_split.py      # → data/processed/{train,val,test}_set.csv, scaler_params.json
python src/03_train_models.py          # → models/*.pkl, results/model_comparison.csv
python src/04_generate_figures.py      # → figures/FIG1–FIG8.png
```

Each script must be run from the repository root, in this order — each depends on the output of the previous one. This exact sequence was re-run from the raw `.xlsx` files during preparation of this repository, and reproduced every reported number and every figure exactly.

## Dataset

- **Source:** MathWorks Hydrogen Refueling Station Simulink model ([documentation](https://www.mathworks.com/help/hydro/ug/hydrogen-refueling-station.html))
- **Samples:** 8,250 total across three scenarios (60-minute refueling cycles, ~2.29 Hz)
- **Class distribution:** HIGH 36.8% (3,036), MEDIUM 35.3% (2,911), LOW 27.9% (2,303)
- **Labeling protocol:** Class assigned by simulation scenario (vehicle initial pressure: 100 / 300 / 500 bar), independent of any input feature — see Section 2.1 of the paper.

## Input Features

Six variables, all independently observable during normal station operation. **Buffer tank pressure is deliberately excluded** because it would directly encode the classification target (see Section 2.3 of the paper for the leakage argument).

| Feature | Description | Unit |
|---|---|---|
| `buffer_temp_high` | High-pressure buffer tank temperature | °C |
| `buffer_temp_medium` | Medium-pressure buffer tank temperature | °C |
| `buffer_temp_low` | Low-pressure buffer tank temperature | °C |
| `vehicle_tank_temp` | Vehicle tank temperature | °C |
| `vehicle_tank_flow` | Hydrogen mass flow rate to vehicle | kg/s |
| `precooler_temp` | Precooler outlet temperature | °C |

## Model Configuration

**MLP (proposed):** hidden layers (64, 32), ReLU activation, Softmax output, Adam optimizer, learning rate 0.001, L2 regularization α = 0.0001, batch size 32, early stopping (patience 10, max 500 epochs), random seed 42. Converged at epoch 84.

**Baselines:** Logistic Regression (L-BFGS, max_iter=1000), Decision Tree (max_depth=10, seed=42), Random Forest (n_estimators=100, seed=42).
